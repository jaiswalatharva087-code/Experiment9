Experiment 09: Custom Server and Node Modules
This project demonstrates how to build a basic Custom HTTP Server using Node.js and how to work with core/custom Node.js modules.

📂 Project Structure
Plaintext
exp09_custom_server/
├── README.md                          # Documentation for the experiment
├── Experiment_09_Custom_Server_And_Node_Modules.docx # Detailed lab manual/guide
└── server.js                          # Main application script for the custom server
🚀 Getting Started
Follow these steps to set up and run the custom server locally on your machine.

Prerequisites
Ensure you have Node.js installed (version 14.x or higher recommended).

Installation & Running
Open your terminal or command prompt.

Navigate to the project directory:

Bash
cd exp09_custom_server
Run the server using Node.js:

Bash
node server.js
Open your web browser or an API testing tool (like Postman or cURL) and navigate to:

Plaintext
http://localhost:3000
(Note: Check server.js to confirm the specific port number configured for this experiment).

📚 Topics Covered
Node.js HTTP Module: Creating a lightweight web server from scratch without external frameworks like Express.

Request & Response Handling: Handling incoming URL routes, HTTP methods, and sending back proper status codes and headers.

Node Modules: Utilizing built-in core modules (such as http, fs, path, or url) to manage server logic.
